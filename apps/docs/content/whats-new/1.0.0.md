- `@butteryui/core` ships every page of the docs as Markdown, with `llms.txt` and `llms-full.txt`, and `@butteryui/react` ships `manifest.json`, the examples as files and what the MCP server answers from, so an agent in an app reads the installed version's docs from `node_modules`, offline. `buttery create` and `buttery init` point an app's agents at them.
- Stylelint fails a `var(--bt-*)` of a name that buttery and the project don't declare, naming the nearest token. Development warnings end with a link to the docs. An `OverflowCluster` in a section's actions folds and unfolds with the page.
- `LayoutGuard` checks a rule or two per frame, so a check doesn't hold up what the page is doing, and the overlap rule is seven times cheaper. The agent evaluation ran its seven tasks with two coding agents, and what it found is fixed: a layout check under load no longer waits on an animation that reduced motion cut short, and a `Grid` with responsive columns warns when nothing above it is a size container.
