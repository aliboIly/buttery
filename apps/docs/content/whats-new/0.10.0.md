- `@butteryui/mcp` gives coding agents five read-only tools over the Model Context Protocol: search, get, scaffold, lint and a layout check, on protocol 2026-07-28 and the 2025 handshake. Lint catches literal values a component's props don't take, such as `gap="16px"`, and says what to write instead.
- `AuthFlow` signs people in or up with a code sent to their email or phone, built from `IdentifierField`, `OneTimeCodeField` and the `useOtpFlow` hook, which work on their own too. The roastery demo and the dashboard template sign in with it.
- The docs search finds sign-in for "login" and "passwordless", and the segmented control for "switch between".
