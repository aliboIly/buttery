- Five read-only tools over the Model Context Protocol: search, get, scaffold, lint and a layout check, on protocol 2026-07-28 and the 2025 handshake.
- Lint catches literal values a component's props don't take, such as `gap="16px"`, and says what to write instead.
- The docs search finds sign-in for "login" and the segmented control for "switch between".
