- `npx create-buttery my-app --template dashboard` starts an app from a template in any folder, with its lint configs, Playwright specs, agent files and the MCP server in each coding agent's config. `buttery add page` writes any of 16 pages from buttery's patterns, wired into a dashboard app's routes and sidebar, and `buttery create component` starts a component on buttery's public parts.
- `buttery check` runs the checks from `@butteryui/test` on pages of the running app, starting its dev server when it isn't running, and prints each problem once with its fix, or every one with `--json`. `buttery doctor` checks an app's setup and `buttery init` sets buttery up in an app you have.
- The dashboard template has a page of every kind, and `buttery_scaffold` sets an example that isn't a whole page inside an `AppPage` or a section of a `Page`, so every scaffolded page has the page grammar's padding and title.
