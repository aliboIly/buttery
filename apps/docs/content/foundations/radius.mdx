The radius scale names the corner radii buttery uses, from `xs` (6px) to `full`. Use a radius token for every rounded corner, and let nested surfaces work out their own.

<RadiusScale />

## Concentric corners

A card inside a panel looks right when its corners follow the panel's: the inner radius is the outer radius less the padding between them. `Surface` does this for you with `radius="auto"`, never going below 4px.

```tsx
import type { ReactElement } from "react";
import { Surface, Text } from "@buttery/core";

export function SettingsGroup(): ReactElement {
  return (
    <Surface level="section" pad={2}>
      <Surface level="card" radius="auto" pad={4}>
        <Text variant="body">Notifications</Text>
      </Surface>
    </Surface>
  );
}
```

```css
/* Do: a radius from the scale. */
.tile {
  border-radius: var(--bt-r-lg);
}

/* Don't: a radius off the scale, which won't nest and fails buttery's stylelint config. */
.tile {
  border-radius: 11px;
}
```
