The palettes are 24 gradient presets and the solid colors taken from them, made to sit well together. Use them where a person picks a color, such as a card's backdrop or a workspace's cover, rather than for interface colors, which come from the [color tokens](/foundations/colors).

## Use a preset

Import them from `@buttery/core/palettes`. `gradientCss` turns a gradient into a CSS background:

```tsx
import type { ReactElement } from "react";
import { gradientCss, gradients } from "@buttery/core/palettes";

const LILAC = gradients.find((preset) => preset.id === "lilac");

export function Cover(): ReactElement {
  return (
    <div
      className="cover"
      style={{ background: LILAC ? gradientCss(LILAC) : undefined }}
    />
  );
}
```

`SwatchGrid` shows the presets as a picker.

## The presets

Three rows run over six hue families, one to a column (butter, apricot, rose, lilac, sky and mint): cream pastels, fresh mids and a deep row. The fourth row is neutral, from paper to graphite. Each stop shifts lightness, chroma and hue a little toward its neighbor, so the blends stay soft.
