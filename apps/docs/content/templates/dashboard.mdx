The dashboard template is a small web app for running a shop: a sidebar of pages beside a top bar with a search, an overview of metric cards and a chart, a table of orders with filters and a page for each order, products by category, search results, a page with nothing in it yet, a feature to turn on, settings with a plan page under them, and a sign-in screen that the account menu's Sign out leads to. It has a page of every kind `buttery add page` writes for an app's shell. Use it for an admin, a back office or any app whose screens are pages of numbers, lists and settings.

## Start from it

<Steps>
<Step>

### Make the app

```bash
npx create-buttery my-app --template dashboard
```

`create-buttery` makes `my-app` in the folder you're in and installs it with the package manager that ran it. The app takes the folder's name, which also replaces "buttery dashboard" in the sidebar.

Inside the buttery repository, `pnpm new-app my-app --template dashboard` copies `apps/templates/dashboard` to `apps/my-app` instead, with the next free port.

</Step>
<Step>

### Start it

```bash
cd my-app
npm run dev
```

Open the address it prints. The template is a web app; `--desktop` adds the Tauri shell to it, as it does to any template.

</Step>
</Steps>

## The overview screen

The app opens on `src/pages/OverviewPage.tsx`, its main screen: the week's sales and orders in two `MetricCard`s, then sales each day in a `BarChart`.

```tsx
import type { ReactElement } from "react";
import { Grid } from "@butteryui/core";
import {
  AppPage,
  ArrowLink,
  BarChart,
  MetricCard,
  PageHeader,
} from "@butteryui/react";
import { ORDER_COUNTS, SALES, WEEK, change, money, total } from "../data.ts";
import { useLink } from "../router.tsx";

/** The dashboard's front page: the week's numbers, then sales day by day. */
export function OverviewPage(): ReactElement {
  const link = useLink();
  const sales = total(SALES.now);
  const orders = total(ORDER_COUNTS.now);
  return (
    <AppPage
      header={
        <PageHeader
          title="Overview"
          description="How the shop did over the last seven days."
        />
      }
    >
      <AppPage.Section title="This week">
        <Grid columns={{ base: 1, md: 2 }} gap={4}>
          <MetricCard
            title="Sales"
            info="Every sale, before refunds and fees."
            value={money(sales)}
            delta={change(sales, total(SALES.before))}
            labels={WEEK}
            series={[
              { key: "now", label: "This week", values: SALES.now },
              {
                key: "before",
                label: "Last week",
                values: SALES.before,
                comparison: true,
              },
            ]}
            formatValue={money}
            updated="Updated just now"
            href={link("/orders")}
          />
          <MetricCard
            title="Orders"
            value={String(orders)}
            delta={change(orders, total(ORDER_COUNTS.before))}
            labels={WEEK}
            series={[
              { key: "now", label: "This week", values: ORDER_COUNTS.now },
              {
                key: "before",
                label: "Last week",
                values: ORDER_COUNTS.before,
                comparison: true,
              },
            ]}
            updated="Updated just now"
            href={link("/orders")}
          />
        </Grid>
      </AppPage.Section>
      <AppPage.Section
        title="Sales each day"
        actions={<ArrowLink href={link("/orders")}>See orders</ArrowLink>}
      >
        <BarChart
          label="Sales each day this week"
          summary={`${money(sales)} this week, against ${money(total(SALES.before))} the week before.`}
          labels={WEEK}
          labelsHeading="Day"
          series={[
            { key: "now", label: "This week", values: SALES.now },
            {
              key: "before",
              label: "Last week",
              values: SALES.before,
              comparison: true,
            },
          ]}
          formatValue={money}
        />
      </AppPage.Section>
    </AppPage>
  );
}
```

`src/App.tsx` shows it inside the `AppShell`, beside the sidebar and under the top bar, as it does every page. `useLink` comes from the template's router, and the numbers from `src/data.ts`.

## Routing

Each template has a small router of its own in `src/router.tsx`, with no dependency, so its pages have real addresses, such as `/orders` and `/settings`. The app uses four of its exports:

<DocsTable
  columns={["Export", "What it does"]}
  rows={[
    [
      "`useRoute()`",
      "Reads the path and the query from the address, and follows it as it changes",
    ],
    ["`useLink()`", "Turns a path in the app into its address"],
    ["`useNavigate()`", "Goes to a path in the app"],
    [
      "`followLinks()`",
      "Makes a click on any link to the app a move within the page, so buttery's link components, which render a plain `<a href>`, work as they are; `src/main.tsx` calls it",
    ],
  ]}
/>

An order's page answers at its own path, such as `/orders/1048`, and the search page reads what to look for from the query, such as `/search?q=tote`.

An app served under a path of its own takes it as `base`, and every link and deep link keeps that start. The docs site shows this template at `/templates/dashboard/preview` with:

```tsx
<App base="/templates/dashboard/preview" />
```
