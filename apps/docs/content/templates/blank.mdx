The blank template is buttery's starter app: the provider, the styles, the bundled font, the layout checks and a Tauri v2 desktop shell, with a page header and a Next steps section on an otherwise empty page. Use it when none of the other templates is close to what you're building, or when you want the desktop app.

<TemplatePreview name="blank" />

## Start from it

<Steps>
<Step>

### Make the app

```bash
npx create-buttery my-app --template blank --desktop
```

`create-buttery` makes `my-app` in the folder you're in, named after the folder, and installs it with the package manager that ran it. `blank` is the default, so `--template blank` can be left out. `--desktop` adds the Tauri shell, so the app also opens as a desktop window.

Inside the buttery repository, `pnpm new-app my-app --template blank` copies `apps/starter` to `apps/my-app` instead, with the next free port, and adds it to the root `tsconfig.json`.

</Step>
<Step>

### Start it

```bash
cd my-app
npm run dev
```

Open the address it prints.

</Step>
<Step>

### Open it as a desktop app

```bash
npm run tauri dev
```

The same app opens in a window of its own.

</Step>
</Steps>

Its one screen is an `AppPage` with a `PageHeader`, from the [app shell](/patterns/app-shell) and [page header](/patterns/page-header) patterns. The [quick start](/get-started/quick-start) builds a first screen in it, and [desktop apps](/get-started/desktop-apps) covers the Tauri shell.
