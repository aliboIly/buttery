The blank template is buttery's starter app: the provider, the styles, the bundled font, the layout checks and a Tauri v2 desktop shell, with one heading on an empty page. Use it when none of the other templates is close to what you're building, or when you want the desktop app.

<TemplatePreview name="blank" />

## Start from it

Inside the buttery repository, this is the command that works today. It copies `apps/starter` to `apps/my-app`, gives the copy its name and the next free port, adds it to the root `tsconfig.json` and installs it. `blank` is the default, so `pnpm new-app my-app` does the same.

```bash
pnpm new-app my-app --template blank
pnpm --filter my-app dev
pnpm --filter my-app tauri dev
```

Once `create-buttery` is published, the same app starts in any folder:

```bash
npx create-buttery my-app --template blank
```
