The editor template is a small web app for making one thing: a header bar with undo and redo, the work on a stage in the middle, and an inspector of its settings beside it, which becomes a sheet on a phone. Use it for a tool where someone shapes a design, a document or a picture and sees it change as they go.

<TemplatePreview name="editor" />

## Start from it

<Steps>
<Step>

### Copy the template

```bash
pnpm new-app my-app --template editor
```

This works inside the buttery repository today. It copies `apps/templates/editor` to `apps/my-app`, gives the copy its name and the next free port, and installs it.

Once `create-buttery` is published, this starts the same app in any folder:

```bash
npx create-buttery my-app --template editor
```

</Step>
<Step>

### Start it

```bash
pnpm --filter my-app dev
```

Open the address it prints. The template is a web app: for a desktop app, start from [blank](/templates/blank), which has the Tauri shell.

</Step>
</Steps>
