The editor template is a small web app for making one thing: a header bar with undo and redo, the work on a stage in the middle, and an inspector of its settings beside it, which becomes a sheet on a phone. Use it for a tool where someone shapes a design, a document or a picture and sees it change as they go.

## Start from it

<Steps>
<Step>

### Make the app

```bash
npx create-buttery my-app --template editor
```

`create-buttery` makes `my-app` in the folder you're in, named after the folder, and installs it with the package manager that ran it.

Inside the buttery repository, `pnpm new-app my-app --template editor` copies `apps/templates/editor` to `apps/my-app` instead, with the next free port.

</Step>
<Step>

### Start it

```bash
cd my-app
npm run dev
```

Open the address it prints. The template is a web app; `--desktop` adds the Tauri shell to it, as it does to any template.

</Step>
</Steps>
