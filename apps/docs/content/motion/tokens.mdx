Motion tokens are the named springs, durations, easings and delays buttery animates with, such as `spring.smooth` or `--bt-dur-fast`. Use a token for every animation, so timings stay consistent and reduced motion can turn them all down at once.

## Springs

Springs move things: positions, sizes and layouts. `spring` from `@butteryui/core` holds them for Motion, and `useButteryTransition(name)` returns one with reduced motion already applied.

```tsx
import type { ReactElement } from "react";
import { motion } from "motion/react";
import { useButteryTransition } from "@butteryui/core";

export function SelectedMark({ x }: { readonly x: number }): ReactElement {
  const transition = useButteryTransition("snappy");
  return <motion.span animate={{ x }} transition={transition} />;
}
```

## Durations, easings and delays

CSS transitions fade and recolor: opacity, colors and shadows. Each duration and easing is a CSS variable. Enters use `--bt-ease-out`, and exits `--bt-ease-in`.
