The motion presets are primitives that animate one kind of change the buttery way, with the right token and reduced motion built in. Reach for a preset before writing an animation of your own, and most screens need no motion code at all.

## Which one

<Cards columns={3}>
<Card title="Presence">

For something that appears and leaves, with a fade, a rise or a pop.

</Card>
<Card title="Morph">

For a container whose height follows its content.

</Card>
<Card title="SharedIndicator">

For a highlight that slides between options, such as a tab's underline.

</Card>
<Card title="Reveal and Stagger">

For content entering the first time it scrolls into view.

</Card>
<Card title="Loop">

For a demo that cycles its states quietly, pausing offscreen and with reduced motion.

</Card>
<Card title="buttery elements">

For an element of your own, through the `enter` and `layout` props of `buttery.div` and the other `buttery` elements.

</Card>
</Cards>

`enter` and `layout` use the same presets, and turn them off with reduced motion. This `buttery.div` rises in when it mounts:

```tsx
import type { ReactElement } from "react";
import { buttery } from "@buttery/react";

export function Notice(): ReactElement {
  return (
    <buttery.div surface="card" pad={4} enter="rise">
      Your export is ready.
    </buttery.div>
  );
}
```
