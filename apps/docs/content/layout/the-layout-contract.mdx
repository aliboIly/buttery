The layout contract is the set of rules buttery's components follow and its checks enforce: things sit in flow with gaps between them, take their sizes from tokens, and never overlap, overflow or move after a press. Follow it in your own screens, and the same checks keep them right at every width.

## The 13 rules

1. Flow layout. Siblings are laid out by `Stack`, `Inline` or `Grid`, with a `gap` from the spacing scale. A component never sets its own outer margin, and negative margins aren't used anywhere.
2. Out-of-flow is owned. `position: absolute`, `fixed` and `sticky` belong to the layer primitives (`Layer`, `Popover`, `Scrim`, `Sticky`, `FloatingLanes`) and to a component's own internal parts, such as a slider's thumb. App code uses those primitives instead.
3. Floating UI goes in lanes. Toasts and notices go in a `FloatingLanes` lane, where items stack 8px apart, never grow wider than the lane and keep clear of sticky bars and anchored toolbars, so a toast and a toolbar never cover each other.
4. Overlays avoid collisions. Popovers and menus open 8px from their trigger and never cover it, move to stay 8px inside the window, and scroll inside when they're taller than the room they have.
5. Sizes come from tokens. Controls take their heights from the height tokens and fixed widths come from the width tokens; everything else takes the width its container gives it.
6. Children can shrink. Every flex and grid child in buttery's primitives has `min-width: 0`, so long content shrinks instead of pushing its neighbors off the screen.
7. Text never overflows. One-line control text truncates with an ellipsis and keeps the whole text in a tooltip; `Text truncate` does both. Content text wraps between words, at most 60 characters a line for body text and 22 for display headings; a word breaks only when it's a long address that can't fit its line. Numbers that change use tabular figures, so a counting number doesn't push what's beside it.
8. Media keeps its shape. Images and canvases keep their aspect ratio, and `FitBox` fits content of a given aspect into the space it has, as large as it can and centered.
9. Containers, not the viewport. Components respond to the room they're given, through container queries, so the same component works in a 340px inspector and on a 1200px page.
10. Overflow by priority, not by wrapping. A row that runs out of room moves its least important items into a "More" menu with `OverflowCluster`, rather than wrapping, overlapping or shrinking its text. Applied filter pills are the exception: `FilterBar` wraps them, since a person has to see each one to remove it.
11. Scrolling stays inside. The page never scrolls sideways, and panels scroll on their own without scrolling the page with them.
12. Sticky things reserve space. Sticky bars publish their height as `--bt-sticky-top`, so a link to a heading lands below them.
13. Nothing moves after a press. Loading states, skeletons and labels that change, such as Continue becoming Finish, keep their exact size, and fonts load without moving text. The one thing that moves after a press is what the press is about.

## Do and don't

The first rule in code:

```tsx
import type { ReactElement } from "react";
import { Stack, Text } from "@buttery/core";
import { Button } from "@buttery/react";

// Do: the parent sets the space between its children.
export function Notice(): ReactElement {
  return (
    <Stack gap={3}>
      <Text variant="title-sm">Payouts are paused</Text>
      <Button size="sm">Add a bank account</Button>
    </Stack>
  );
}
```

```css
/* Don't: a margin on a child, which moves it wherever it's reused. */
.notice-button {
  margin-top: 12px;
}
```

## How it's checked

- `LayoutGuard` runs in development and outlines anything that overlaps, overflows, truncates without saying so or drifts off the scale, text stacked so close its descenders crowd the next line, words broken across lines and controls in a row that don't line up. ⌥⇧L hides and shows the outlines, and ⌥⇧G shows the page grid.
- `expectButtery(page)` from `@buttery/test` runs the same checks in Playwright, at every width, theme and density you ask for, and reports each problem with how to fix it.
- buttery's stylelint config fails raw colors, lengths off the scale, `z-index` values that aren't a layer band, negative margins and `transition: all`.
