`Stack`, `Inline` and `Grid` lay out their children in a column, a row or a grid, with a `gap` from the spacing scale between them. Use them for every arrangement of siblings, so space belongs to the parent and a component looks the same wherever it's placed.

## Choosing one

<Cards columns={3}>
<Card title="Stack">

For a column: a form's fields, a card's title over its text.

</Card>
<Card title="Inline">

For a row: a button group, an icon beside its label. `wrap` lets it wrap, and `uniform` makes every child as wide as the widest, for a row of equal buttons.

</Card>
<Card title="Grid">

For columns that change with the room, stepping at 640px and 1024px of the container it's in.

</Card>
</Cards>

`columns={{ base: 1, md: 2, lg: 3 }}` gives a `Grid` one column below 640px of its container, two from 640px and three from 1024px.

All three take `align` and `justify`, and render a `div` unless you pass `asChild` to lay out an element of your own, such as a `ul`.

> **Lists.** When you lay out a `ul` or `ol` with `asChild`, give it `role="list"`. The role drops the bullets and the indent, and keeps the list announced as a list in Safari, which drops that along with the bullets.

`Stack`, `Inline` and `Grid` together in a plan picker:

```tsx
import type { ReactElement } from "react";
import { Grid, Inline, Stack, Text } from "@buttery/core";
import { Button } from "@buttery/react";

export function PlanPicker(): ReactElement {
  return (
    <Stack gap={4}>
      <Text variant="title-md">Choose a plan</Text>
      <Grid columns={{ base: 1, md: 3 }} gap={4}>
        <Text variant="body">Starter</Text>
        <Text variant="body">Roaster</Text>
        <Text variant="body">Wholesale</Text>
      </Grid>
      <Inline gap={2} justify="end">
        <Button variant="soft">Compare plans</Button>
        <Button variant="primary">Continue</Button>
      </Inline>
    </Stack>
  );
}
```

`Divider` draws a hairline between children, across a stack or down a row. It's decorative unless it separates groups a screen reader should know about.
