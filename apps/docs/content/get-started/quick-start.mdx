This page builds a first screen in the starter: a card that turns order emails on and off. Follow it once to see how buttery's pieces fit together, primitives for layout, components for controls, and the layout check at the end. It assumes you've cloned the repository and run `pnpm install`, as [Installation](/get-started/installation) shows.

## What you'll build

The finished screen, running. Press Save, or switch the site to dark with the theme button in the top bar.

## Build it

<Steps>
<Step>

### Start a new app

```bash
pnpm new-app first-screen
pnpm --filter first-screen dev
```

The starter opens with a page header and an empty section. Everything below goes in `apps/first-screen/src/App.tsx`.

</Step>
<Step>

### Lay out the card

Replace the file with this. `Stack` and `Inline` lay the card out, `Surface` gives it its background, corners and shadow, and `Switch` and `Button` are the controls. There are no styles to write: spacing comes from `gap` and `pad`, and everything else from the components.

<QuickStartCode />

</Step>
<Step>

### Try it

Save the file, and the page shows the card. Press Save and a toast rises from the bottom of the window; switch the system to dark mode and the card follows, since every color in it is a token with a value for each scheme.

</Step>
<Step>

### Check the layout

In development, `LayoutGuard` outlines anything on the page that overlaps, overflows or sits off the spacing scale. Narrow the window to a phone's width and nothing should light up. The starter's Playwright test runs the same checks at a phone's width and a desktop's, in light and dark:

```bash
pnpm test:e2e apps/first-screen
```

</Step>
</Steps>

> **Keyboard shortcuts.** ⌥⇧L hides `LayoutGuard`'s outlines and ⌥⇧G shows the page's grid, while you work.
