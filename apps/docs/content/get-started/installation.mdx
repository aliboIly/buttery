buttery isn't on npm yet, and its repository is private, so until the first npm release you need access to the repository to use it. With access, an app starts as a copy of the starter inside the repository, and this page takes you from cloning it to an app running on the web and as a desktop app.

## What you need

- Access to the buttery repository on GitHub. Ask its maintainer for it.
- Node 22.18 or later in the 22 line, 24.11 or later in the 24 line, or 26 and later. That's the `engines` range in the repository's root `package.json`.
- pnpm 12. The root `package.json` pins 12.14.0 as its `packageManager`, and on Node 22 and 24, `corepack enable` installs that version for you.
- For the desktop app, Rust through `rustup` and, on macOS, the Xcode Command Line Tools (`xcode-select --install`), which Tauri v2 builds with.

## Get the repository

Clone it and install everything in it:

```bash
git clone https://github.com/aliboIly/buttery.git
cd buttery
pnpm install
```

`pnpm install` installs every package and app in the repository and turns on its git hooks.

## Start a new app

From the repository's root, copy the starter under a new name and start it:

```bash
pnpm new-app my-app
pnpm --filter my-app dev
```

`pnpm new-app` copies `apps/starter` to `apps/my-app`, gives the copy its name and the next free port, and installs it. The app already loads buttery's styles, wraps itself in `ButteryProvider` and runs the layout checks in its Playwright tests. Add `--template dashboard`, `editor` or `marketing` to start from one of the [templates](/templates/blank) instead.

## Run it as a desktop app

The starter is also a Tauri v2 app. With Rust installed, open it in a desktop window:

```bash
pnpm --filter my-app tauri dev
```

## What an app needs in its code

An app on buttery imports two stylesheets once, at its entry, and renders inside `ButteryProvider`:

```tsx
import "@buttery/core/styles.css";
import "@buttery/react/styles.css";
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import { ButteryProvider } from "@buttery/react";
import { App } from "./App.tsx";

const container = document.getElementById("root");
if (!container) throw new Error("index.html needs a #root element.");

createRoot(container).render(
  <StrictMode>
    <ButteryProvider>
      <App />
    </ButteryProvider>
  </StrictMode>,
);
```

`ButteryProvider` sets the color scheme, density and motion preference for everything inside it, and mounts the layers that menus, dialogs and toasts open into.

## Server rendering

The components render to HTML with `react-dom/server`, which this site uses to prerender every page, but they use state and effects, so with React Server Components, render them from your own client components.
