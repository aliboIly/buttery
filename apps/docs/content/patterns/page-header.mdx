A page header is the top of an app page: breadcrumbs when the page is nested, the title with an optional badge or value, one line about the page, and the page's actions at the end. Use `PageHeader` on every app page, so pages read the same way from one to the next.

## The page grammar

Every page in an app shell follows one order, from the top:

1. Breadcrumbs, only on a nested page.
2. The title and its actions, one of them primary.
3. A one-line description.
4. Tabs and filters.
5. The page's content.

`PageHeader` builds the top of it. When its actions don't fit, they fold into a "More page actions" menu.

This header shows a count, with what it counts behind an info button, and two actions. `priority={1}` keeps New order, the primary action, in the row after Export has folded away.

```tsx title="src/OrdersHeader.tsx"
import type { ReactElement } from "react";
import { Download, Plus } from "lucide-react";
import { PageHeader } from "@butteryui/react";

export function OrdersHeader(): ReactElement {
  return (
    <PageHeader
      title="Orders"
      value="1,284"
      valueInfo="Orders placed in the last 30 days."
      actions={
        <>
          <PageHeader.Action
            icon={Download}
            label="Export"
            onSelect={() => undefined}
          />
          <PageHeader.Action
            variant="primary"
            icon={Plus}
            label="New order"
            priority={1}
            onSelect={() => undefined}
          />
        </>
      }
    />
  );
}
```
