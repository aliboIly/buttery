Search in a buttery app has two parts: `CommandSearch` in the top bar, which suggests filters and shows grouped results as a person types, and `SearchResults`, the page of every result, grouped by where each was found. Use both, so a search that's more than a quick jump has somewhere to go.

Sending a search from the field opens the results page with the same query: `parseSearch(value, filters, { sent: true })` reads the field's text and its finished filters, such as `status:shipped`, into one query both parts understand.

```tsx
import type { ReactElement } from "react";
import { SearchResults, parseSearch } from "@buttery/react";
import type { SearchFilter, SearchSource } from "@buttery/react";

export function ResultsPage({
  search,
  filters,
  sources,
}: {
  readonly search: string;
  readonly filters: readonly SearchFilter[];
  readonly sources: readonly SearchSource[];
}): ReactElement {
  return (
    <SearchResults
      query={parseSearch(search, filters, { sent: true })}
      sources={sources}
    />
  );
}
```
