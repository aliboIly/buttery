A settings page is a detail page for one area of settings, such as pickup or the team, made of sections that each hold one kind of setting. Build it from `SettingsPage`, `SettingsSection` and `SettingRow`, and every settings page reads the same.

## The parts

<Cards columns={3}>
<Card icon="template" title="The page">

`SettingsPage`: breadcrumbs back to the settings index, the title with an optional scope badge, one line about the page, then its sections, at most 960px wide.

</Card>
<Card icon="blocks" title="Sections">

`SettingsSection`: a heading, one line about it and its one action, then its content. A section can load on its own while the rest of the page is ready, or be a form whose Save waits for a change.

</Card>
<Card icon="wrench" title="Rows">

`SettingRow`: one setting in a section, with what it is, its current state under it, and its one action at the end, primary only when it turns something on.

</Card>
</Cards>

A page for pickup, with one section:

```tsx title="src/pages/PickupSettings.tsx"
import type { ReactElement } from "react";
import {
  Breadcrumbs,
  SettingsPage,
  SettingsSection,
  Switch,
} from "@butteryui/react";

export function PickupSettings(): ReactElement {
  return (
    <SettingsPage
      title="Pickup"
      breadcrumbs={
        <Breadcrumbs items={[{ label: "Settings", href: "/settings" }]} />
      }
      description="When and where customers collect their orders."
    >
      <SettingsSection
        title="Pickup"
        description="Let customers collect at the roastery."
      >
        <Switch label="Offer pickup" defaultChecked />
      </SettingsSection>
    </SettingsPage>
  );
}
```
