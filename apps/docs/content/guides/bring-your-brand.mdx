buttery's defaults are neutral on purpose, so an app's own brand shows. This guide puts yours on top: an accent and a primary color, warmer or cooler grays, rounder or tighter corners, your own mark and your own typeface.

## Add your brand

<Steps>
<Step>

### Set your colors and corners

`createTheme` turns your brand's colors and a few choices into a theme, and `ButteryProvider` applies it through its `theme` prop:

```tsx
import type { ReactElement } from "react";
import { createTheme } from "@buttery/core";
import { ButteryProvider } from "@buttery/react";
import { App } from "./App.tsx";

const brand = createTheme({
  accent: "#c2410c",
  neutral: "warm",
  radius: "soft",
});

export function Root(): ReactElement {
  return (
    <ButteryProvider theme={brand}>
      <App />
    </ButteryProvider>
  );
}
```

> **Change roles, not values.** Set `accent`, not the color of one button. [Theming](/foundations/theming#your-own-theme) has every option.

</Step>
<Step>

### Put in your mark

Put your own logo in the places buttery puts its own: a `NavBar`'s `brand`, the `switcher` of the `Sidebar` in an `AppShell`, and a `HeaderBar`'s `mark`. Keep buttery's mark for buttery itself.

</Step>
<Step>

### Set your typeface

buttery sets text in Inter. To use your own typeface, load it from the app's own files and set `--bt-font-sans` on `:root` after buttery's stylesheet. Don't load fonts from the network: desktop apps have to work offline.

The type roles keep their sizes, so check long words in narrow places with `expectButtery`.

</Step>
</Steps>
