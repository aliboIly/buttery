This guide moves an existing React app onto buttery without a rewrite: wire up the provider, check the layout, then convert a screen at a time from the top down. Follow it when an app already works and you want it to look, move and lay out like buttery.

## Move the app across

<Steps>
<Step>

### Wire it up

Import buttery's two stylesheets at the app's entry and wrap the app in `ButteryProvider`:

```tsx title="src/main.tsx"
import "@buttery/core/styles.css";
import "@buttery/react/styles.css";
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import { ButteryProvider } from "@buttery/react";
import { App } from "./App.tsx";

const container = document.getElementById("root");
if (!container) throw new Error("index.html needs a #root element.");

createRoot(container).render(
  <StrictMode>
    <ButteryProvider colorScheme="light">
      <App />
    </ButteryProvider>
  </StrictMode>,
);
```

buttery's styles sit in CSS cascade layers, so a style the app sets itself still wins. Whatever the app leaves to the browser changes, through buttery's base styles and a small reset:

> **Light and dark.** `ButteryProvider` follows the system's light or dark setting, which switches those colors. Pass `colorScheme="light"`, as above, until the app's own styles are ready for dark.

The app also gains buttery's tokens, the layers that menus, dialogs and toasts open into, and `LayoutGuard` in development.

</Step>
<Step>

### See where it stands

Run the app in development and narrow the window from wide to a phone's width. `LayoutGuard` outlines what overlaps, overflows or sits off the spacing scale.

Then add a Playwright test for each main page, and keep its report as the list of what to fix:

```ts title="e2e/layout.spec.ts"
import { test } from "@playwright/test";
import { expectButtery, quickMatrix } from "@buttery/test";

test("the home page is buttery", async ({ page }) => {
  await page.goto("/");
  await expectButtery(page, { ...quickMatrix, name: "home" });
});
```

</Step>

<Step>

### Keep it there

Add `@buttery/lint`'s configs and the `expectButtery` tests to the app's checks, so a screen stays buttery once it's converted. [Lint configs](/tools/lint-configs) has both config files.

</Step>
