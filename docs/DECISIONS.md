# Decisions log

Every judgment call that deviates from or fills a gap in the specs goes here: date, decision, why, alternatives considered.

| Date | Decision | Why |
|---|---|---|
| 2026-10-19 | The look comes from one set of local app captures; layout and motion behavior come from a second set of page captures. No branding from either. | buttery has its own identity. |
| 2026-10-19 | Caption text uses `#6b6b6b`, not the reference `#8a8a8a`. | Reference fails WCAG AA; `#6b6b6b` passes on white, section and app backgrounds. |
| 2026-10-19 | Toast height snapped from measured 38px to `--bt-h-button` (36); menu item padding-x snapped from ~14 to 12; empty-state title→body gap 6 → 8. | Keep values on the token scale. |

| 2026-10-19 | Hit areas ≥ 24×24 (WCAG 2.5.8), standalone buttons ≥ 28 tall; small visuals extend hit areas with `[data-bt-hit]`. | A flat 28px rule would fail the spec's own thumb, chip and color dot. |
| 2026-10-19 | Layout checks run in Chromium **and** WebKit. | Tauri on macOS renders with WKWebView. |
| 2026-10-19 | Dark theme, dialog-open motion and drop-zone drag-over are derived, not measured. | Not in the references; need a visual pass. |
| 2026-10-19 | `AGENTS.md` is the single source of agent instructions; `CLAUDE.md` imports it with `@AGENTS.md` and `.gemini/settings.json` loads it. | One set of rules for every agent; `docs/DX_AND_AI.md` explains why each file exists. |

| 2026-10-19 | Strict TypeScript + React 19 bar (ref as prop, pure render, no `any`/`!`/enums, typescript-eslint strict-type-checked, zero warnings). | Code quality is part of the product. |

| 2026-10-20 | The repo is public from the first commit. `reference/` and `PROMPTS.md` stay local and untracked, and a `pre-commit` hook and `pnpm check` fail if either is tracked. | 2026-10-20 | MIT license. | Maintainer's call. |
| 2026-10-20 | Attribution and filler-sounding text are banned everywhere. Agent tool names appear only in `AGENTS.md`, `CLAUDE.md`, `.claude/`, `.gemini/`, `docs/DX_AND_AI.md`, `docs/AGENT_EVAL.md`, `packages/cli/` and `packages/mcp/`; paths of files in the repo can be referenced anywhere. | 2026-10-20 | Layout checks wait for buttery's settled flag (`data-bt-settled` on `<html>`, set while its running-animation count is zero) and run with reduced motion emulated. | 2026-10-20 | `pnpm check` runs `expectButtery` on changed pages at 390 and 1280, light and dark, comfortable, in Chromium and WebKit. | 2026-10-20 | Text stacks use `text-box: trim-both cap alphabetic` where supported. | 2026-10-20 | Compact density keeps `--bt-h-sm` at 28. | Standalone buttons are never shorter than 28. |
| 2026-10-20 | The inner card's edge is `shadow-card`'s ring, with no border. | The capture shows a translucent ring; adding a border would make a 2px edge. |
| 2026-10-20 | Dark-theme edges, shadows, accent, skeleton and `text-disabled-subtle` are derived in Phase 1 and marked _derived_; a light ring replaces the black one. | The references are light only, and a 6% black ring vanishes on dark surfaces. The maintainer does the visual pass. |
| 2026-10-20 | Two sanctioned size animations: `Morph`'s height and the `MorphMenu` viewport's size and position. `backdrop-filter` joins the animatable properties. | Radix exposes the menu viewport's size as CSS variables, and the blur scrim is a `backdrop-filter`. |
| 2026-10-20 | `position` lives only in core's layer primitives and in a component's own `data-bt-part` internals; the overlay components in `@buttery/react` build on the primitives. | LAYOUT_RULES and ARCHITECTURE disagreed about where the overlays live. |
